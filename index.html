Computer Hardware Devices Quiz

Test your knowledge of input, output, storage and processing devices.

Section A – What Do You Know?

Instructions: Type your answer into the entry box for each question. When you have answered all four questions, click Verify Section A. A ✓ will appear for a correct answer and an ✗ for an incorrect answer.

Section B – Identify the Hardware

Instructions: For each hardware device, select the correct option under Type of Hardware and the correct option under Uses. Then click Verify Section B.

Section C – Choose the Hardware for the Task

Instructions: Read each scenario. Choose the hardware device that could be used for the task from the Use a: dropdown box.
1. You want to type an assignment using a computer.
2. You want to view your assignment on the computer screen.
3. You want to save your assignment so that you can use it later.
4. You want to print a paper copy of your assignment.
5. You want to make a digital copy of a paper document and put it on the computer.
